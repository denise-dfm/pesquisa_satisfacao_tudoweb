Foi utilizada a estrutura de repetição FOR para realizar a coleta das respostas dos entrevistados.
Os dados coletados foram: nome, idade e opinião sobre o atendimento.
Foi utilizada a estrutura de decisão IF/ELIF para verificar a opção escolhida.
As respostas "EXCELENTE" e "RUIM" foram armazenadas em contadores.
Ao final da execução, o programa exibe a quantidade total de respostas "EXCELENTE" e "RUIM".
